# Tic-Tac-Toe

Run the game with:

```bash
python main.py

The launcher opens the game in your default browser and serves the files locally so JavaScript modules load reliably.
Keep the terminal open while playing. Press Ctrl+C in the terminal when you want to stop the launcher.

``` Project layout ```

index.html — Page structure and audio elements.
css/style.css — The game''s visual design and responsive styling.
js/game.js — Board state, turns, winner checks, draws, and scores.
js/ai.js — CPU move strategy.
js/ui.js — Board rendering, screen changes, scoreboard, and result overlay.
js/audio.js — Background music and sound effects.
js/main.js — Connects modules and handles button events.
assets/audio/ — Music and game sound effects.
